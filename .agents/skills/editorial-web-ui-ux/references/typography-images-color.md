# Typography, Images, and Color

Use these rules when defining type hierarchy, image direction, cropping,
visual weight, or palette.

## Contents

1. Typography
2. Images
3. Color

## 1. Typography

- Use no more than two font families: a display face and a text/interface face.
- Use no more than four weights.
- Define Display XL, Display L, Heading M, Body, Caption, and Label roles.
- Use only one display-level element per section.
- Use Display XL in no more than two sections on one page.
- Keep body copy left-aligned unless it is extremely short.
- Avoid centered paragraphs longer than two lines and uppercase paragraph text.
- Reserve vertical or experimental type for secondary information.
- Keep body lines around 45–80 characters.
- Avoid important text over busy images.
- Reduce contrast for secondary information instead of making it unreadably
  small.

Suggested ranges:

- Desktop Display XL: `64–144px`
- Desktop Display L: `44–96px`
- Desktop Heading M: `28–48px`
- Desktop Body: `16–20px`
- Mobile Display XL: `44–64px`
- Mobile Display L: `36–48px`
- Mobile Heading M: `24–32px`
- Mobile Body: `16–18px`
- Caption minimum: `12px`
- Label minimum: `11px`

Treat these as readable bounds. Adapt them to the typeface, content, stage
scale, and existing design system.

## 2. Images

Assign every image one role:

- Hero: establish primary visual identity
- Primary: communicate the section's main content
- Supporting: add context without competing
- Detail: show material, process, texture, or close-up information
- Decorative: add atmosphere without carrying essential meaning

Follow these rules:

- Use one primary image per section.
- Limit a section to three meaningful image ratios.
- Keep primary imagery visually dominant after responsive stacking.
- Vary image size according to content importance.
- Check focal subjects before cropping faces, products, architecture, or art.
- Use full-bleed media only for high-priority content and not in consecutive
  sections.
- Avoid arbitrary filters and generic stock imagery when contextual material
  exists.
- Use captions when context is necessary.
- Define dimensions or aspect ratios to prevent layout shift.
- Load thumbnails and responsive sizes instead of unnecessary full-resolution
  media.

Useful starting ratios:

- Hero landscape: `16:9`, `3:2`, or `4:3`
- Editorial portrait: `3:4` or `4:5`
- Project overview: `4:3` or `3:2`
- Detail: `1:1` or `4:5`
- Cinematic full width: `21:9` or about `2:1`

Do not make primary and supporting images equally dominant.

## 3. Color

- Begin with one neutral foundation.
- Add one primary accent when needed.
- Add secondary colors only for a clear function.
- Use accents for emphasis, state, navigation, or brand expression.
- Maintain sufficient contrast for text and controls.
- Avoid equal accent intensity across all elements.
- Avoid unrelated bright colors, excessive gradients, and mechanical
  background alternation.
- Prefer a softer tonal black and white when the brand benefits from it.
- Keep color behavior consistent across pages and interaction states.
